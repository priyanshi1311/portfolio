# Priyanshi | Developer Portfolio (Pure HTML, CSS, JS)

A modern, high-performance **HTML5 + CSS3 + Vanilla JavaScript** portfolio website designed for **Priyanshi** — Full Stack Developer & Final Year B.Tech CSE student (CGPA: 8.02/10, COER University Roorkee).

✨ **Key Highlights**:
- **Dual Theme System**: Seamless toggle between an ultra-refined Dark Theme and a clean Light Theme (with persistent `localStorage` preference and zero flash of unstyled content).
- **Pure & Zero-Dependency**: Zero framework, no build step, no npm packaging required — runs by opening `index.html` directly in any web browser or via any static server.
- **Interactive Modals**: Dynamic deep-dive project inspector & ATS-compliant printable resume modal.

---

## 📁 File Structure

- **`index.html`**: The complete website structure, sections, modals, responsive nav, and theme toggle controls.
- **`style.css`**: Dual theme system variables (`:root` / `html.dark`), smooth glassmorphism, animations, radar pings, and print media queries.
- **`script.js`**: Vanilla JS for theme switching, category filters, project modals, ATS resume modal, confetti, and clipboard operations.
- **`serve.js`**: Lightweight zero-dependency static server (optional).
- **`README.md`**: Project documentation and running guide.

## 🚀 How to Run

### Method 1: Direct File
Simply open `index.html` directly in your web browser (Chrome, Edge, Firefox, Safari).

### Method 2: With Node.js Static Server
```bash
node serve.js
# Opens at http://localhost:5173/
```
